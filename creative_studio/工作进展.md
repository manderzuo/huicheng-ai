# 独立视频创作流水线：工作进展

更新：2026-10-31

## 用户要求与边界

- 单独建设和测试，不集成现有 FishFleet 主界面，整体测试通过后再考虑接入。
- 输入一个话题和参考图，生成指定数量、内容有差异的多套视频提示词，再调用已有视频生成 MCP。
- 时长 **5–15 秒**；视频生成并发最多 **5**。
- 视频必须逐条人工审核；同一视频允许分配给多台手机，不限制多账号发布同一视频。
- 支持随机分配或指定手机；发布前必须明确确认。
- **没有用户明确命令，不执行真实视频生成，不发布。** 本地模拟测试可继续，不产生视频生成费用。

## 当前实现

- 独立 FastAPI 服务：`backend.py`；界面：`static/index.html`、`static/app.js`、`static/style.css`。
- 项目保存到 `creative_studio/data/<项目ID>/`；项目及任务状态写入 JSON。
- 用现有 `_llm_chat`、话题和参考图生成 N 条提示词，要求非空、数量一致且文本不重复；可逐条编辑。
- 提示词结构参考仓库 `src/optimizer/videoRules.js`：主体、动作、镜头、时间轴、连续性、参考图及声音等；是重新编写的规则，并非直接运行原仓库。
- 图片上传限制 10 MB，检查图片类型；项目数量 1–20，时长 5–15 秒。
- 生成前需显式确认可能产生费用；使用最多五线程提交 MCP 请求，超时或上游结果不明标记 `unknown`，不会自动重试；服务重启时正在运行或排队的任务也标记未知。
- 本地生成视频可以在界面预览并逐条审核；只有审核通过的素材可以进入计划，改为拒绝时自动移出计划。
- 支持获取群控手机、随机分配或手动逐视频多选手机；目前**只保存发布计划，不会执行发布**。
- 本地服务对非安全方法做 Origin / Sec-Fetch-Site 跨站请求拦截。

## 未完成和后续核实

1. **没有真实视频 MCP 端到端验证**。当前仅接受服务返回可读取的本地视频路径；远程 URL、异步任务 ID、参考图路径是否被实际服务接受均未验证。服务会把其他情况记为结果未知，不能假称生成成功。
2. **未接入自动发布**：需要后续设计视频入库、逐视频文案、真实账号身份、发布调度及人工发布确认，不能把已有计划表当作已发布。
3. 模拟测试不证明真实 MCP 的并发能力、收费行为、输出格式或画面品质；避免以本地提示词去重宣称视频必然去重。
4. 对生成费用、请求幂等、失败恢复、任务中断、素材/项目管理及异常返回应继续完善；谨慎处理任意上游返回路径与远程下载安全。
5. 自动目标记录的原文有旧的 5–10 秒表述，以用户更正后的 **5–15 秒**为准。

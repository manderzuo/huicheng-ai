> 2026-10-31 22:02–22:10，手机4 实测
> 结论先行：**在未关注的陌生人主页上，找不到任何私信入口。**

---

## 一、为什么查这个

要做「评论区截流 → 自动私信」，必须先知道**从哪里发起一条新私信**。
如果连入口都进不去，后面的输入框、发送键都无从谈起。

## 三、结论：关注之后也没有

主人已授权，实测做了「关注 → 看主页 → 取消关注」的完整验证：

| 步骤 | 观察 |
|---|---|
| 未关注时主页 | 只有「+ 关注」一个大按钮 |
| **点击关注后** | 按钮变成「已关注」，**右侧多出一个「∨」箭头** |
| 点「∨」/「已关注」 | 弹出三项菜单：**加入特别关注 / 设置分组 / 取消关注** —— **没有私信** |
| 已关注状态下整页扫描 | 头顶只有返回/消息/搜索/更多；主体只有关注按钮 + 数据 + tab；**全页无「私信」二字** |
| 取消关注 | 成功，按钮恢复「+ 关注」，账号已还原 |

**最终结论**：B站 9.16.1 Android 版，在用户主页（`LocalAuthorSpaceActivity`）上**不提供「主动发起私信」的入口**，未关注和已关注都一样。

## 五、附：评论回复链路（已完全打通，未发送）

```
视频详情页
  → 点「评论」tab（(180,790)）
  → 点某条评论的「回复」（label="回复"，View，如 (294,1533)）
  → 底部弹出输入态：
       输入框   id = tv.danmaku.bili:id/edit   (EditText，focused)
       占位提示 「回复 {用户名}：」（一输入就消失）
       工具条   转到动态 / 表情 / @ / 图片
       发送键   text = "发布"  ← 真正发送，右下角 (946,1685,110×95)
  → 输入文字后「发布」由灰变粉
  → 【到此为止，不点发布】
```

**三个坑**：
1. 发送键叫「发布」，**没有 id**，只能按 text 定位；
2. 「发布」的 `disabled` 属性在无障碍树里**不体现**——空内容时也能被匹配到，自动化必须自己判断输入框有无内容；
3. 左下角「转到动态」是**隐藏副作用开关**，勾上会连发一条动态。

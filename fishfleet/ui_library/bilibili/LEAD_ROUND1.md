## 三、最关键的两个发现

### 1. 用 DeepLink 搜索，彻底绕开输入法

B站 搜索框会**自动填充搜索建议**，`set_text` 写完立刻被覆盖：

```
输入「挖矿木马」→ 变成「电脑中病毒cpu占用高」
输入「矿池」    → 变成「darkanddarker挖矿」
```

加清空、加零延迟回车都拦不住。改用：

```
bilibili://search?keyword=<urlencode>
```

实测全部关键词正确带入，**100% 可靠**。

### 2. 锚点越硬越好

| 锚点 | 可靠性 | 说明 |
|---|---|---|
| 视频标题 | 低 | 会被截断、被简介小标题抢占 |
| UP 名 | 中 | 结果卡原样显示，但重名 |
| **`aid` / `mid`** | **100%** | 从 `dumpsys` Intent 读，数值型 |

评论者 UID 靠点昵称进主页、从 Intent 取 `mid`，实测 213/213 全部拿到。

## 五、外部限制

### B站 接口限流

测试后期（约 00:00 起）搜索页持续返回：

- 「正在加载数据…」长时间不结束
- 「加载失败，请稍后再试」
- 用户主页 WebView 同样加载不出来

但 B站 首页（自绘 UI）正常、ping 0.8ms，说明**是接口限流，不是网络问题**。

推测原因：当晚累计搜索十几轮、二十多个关键词，触发频控。

**处理**：
- 代码已加「加载失败」自动重试（点「再试一次」，最多 3 次）
- 加轮询等待（最多 12 × 2.5 秒）
- 限流期间退避等待，不硬采

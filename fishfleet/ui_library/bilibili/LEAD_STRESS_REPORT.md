## 三、找到的 BUG

### BUG 1：搜完关键词不会自动换词（影响产量）

**现象**：关键词「矿机」只采到 37 条就结束了，离 200 目标差很远。

**原因**：`collect_aigc.py` 的主循环是"搜一个词 → 把结果翻完 → 结束"。
搜索结果的卡片全部见过之后 `swipe_rounds` 到上限，直接退出。

**影响**：单关键词视频量少时，产不出量。本次靠手工换词（矿机→矿卡）才补到 213。

**建议**：改成关键词队列，一个词翻完自动切下一个，直到达标。

---

### BUG 2：账号已注销的用户必然失败（已修）

**现象**：

```
领到 66a623fa  账号已注销  uid=3546904415701938
  ✗ 失败: 没进入私信会话页（activity=LocalAuthorSpaceActivity）
```

**原因**：注销账号的 B站 主页**没有私信图标**，点 (852,127) 无响应。

**修复**：
1. `BAD_AUTHOR` 加 `账号已注销|用户已注销|已注销`，采集阶段就丢弃
2. 该条历史记录从 `failed` 改为 `skipped`（不是我们的错，也会干扰重试统计）

---

### BUG 3：UP 的 UID 偶发拿不到（未修）

**现象**：213 条里有 **5 条 `up_uid` 为空**。

**原因**：点「UP主头像」后 5 秒内没进主页（网络慢或头像元素位置变了），
`LocalAuthorSpace` 判断失败就跳过，没重试。

**影响**：不影响私信（私信用的是 `commenter_uid`），但少了个溯源字段。

**建议**：加一次重试，或改成"点昵称"兜底。

---

### BUG 4：广告文案仍有漏网（已修）

**现象**：2 条评论正文是电商广告。

**修复**：`BAD_CONTENT` 增加 `¥数字` 和 `轻点两下查看详情` 特征。

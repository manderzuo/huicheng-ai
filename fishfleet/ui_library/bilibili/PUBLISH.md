## 一、完整链路

```
首页底部「+」(home_publish_icon)
  ↓
CenterPlusMainActivity               相册选素材（最近项目 / 全部·视频·照片 / 草稿箱）
  ↓ 点素材 → 出现「智能成片」「去编辑」
「去编辑」
  ↓
BiliEditorMainActivity               B站自带视频编辑器（模板/剪辑/音乐/文字…）
  ↓ 右上角「下一步」
ManuscriptUpActivityV5               投稿信息页 ← 真正填表的地方
  ↓ 填标题 / 简介
「发布」
  ↓
回到 MainActivityV2（首页）
```

**和抖音最大的不同**：抖音 SEND intent 直达编辑页；B站 走创作中心，中间**必须经过视频编辑器**点「下一步」，跳不过去。

## 三、五个坑（都是实测踩出来的）

### 坑 1：u2 的 `click()` 点不动「发布」
```
dev.d.click(663, 1765)   → activity 不变，什么都没发生
adb shell input tap 663 1765 → 立刻发布成功，activity 跳回首页
```
u2 走 UiAutomation 注入，B站 的发布按钮（TextView 自绘）会吞掉事件。
**`device.tap()` 已改成 `input tap`**，这是本次最重要的修复。

### 坑 2：`monkey` 在 u2 连上后完全失效
u2 一连上就占住 UiAutomation，此后 `monkey` 注入报 `already registered`，
**App 根本起不来**。已把 `start_app` 改成 `am start -n <resolve-activity>`。

### 坑 3：简介填了等于没填（最阴）
```python
点 et_desc → 弹层打开
弹层里的输入框是 etEditor，不是 et_desc
确认按钮叫「确认」，不是「确定」
```
原来的代码：找 EditText[0]（可能打到标题框）+ 找"确定"（找不到）→ **返回 True 但内容为空**。
现在：按 `resourceId` 精确写 `etEditor`，点「确认」，**写完回读校验**，不通过就返回 False。

### 坑 4：activity 名是短名
u2 返回 `.MainActivityV2`，不是 `tv.danmaku.bili.MainActivityV2`。
拿全名比对会**永远不相等**，导致误判"不在首页"、乱按 BACK。

### 坑 5：截图文件名
`serial` 是 `IP:端口`，冒号在 Windows 文件名里非法，`open()` 直接失败留 0 字节残文件。
已在 `shot()` 里做字符清洗。

## 四、怎么确认「发布成功」（重点）

实测三种证据，按可靠性排序：

### ① 稿件管理列表（最硬）
```
我的 → 创作中心 → 稿件管理 → 视频
```
列表按时间倒序，**第一条就是刚发的**，显示标题 / 时长 / 发布时间 / 播放·点赞·评论·分享数。
刚发布时数据全是 `-`。

### ② 动态数 +1（辅助）
我的页的「动态」计数会 +1（发视频会自动生成一条动态）。
本次实测：**13 → 14**。

### ③ activity 离开 ManuscriptUpActivityV5（最弱）
代码里 `verify()` 用的是这个，快但只能说明"页面走了"，不等于"投稿成功"。
**要确认真发出去，必须看①或②。**

## 五、怎么删除一条稿件

```
我的 → 创作中心 → 稿件管理 → 找到目标 → 「更多」
  → 菜单：互动管理 / 删除 / 可见范围 / 弹幕转移 / 必火推广 / 章节管理
  → 点「删除」
  → 二次弹层：设为仅自己可见 / 删除作品（永久删除且无法找回）
  → 点「删除作品」
  → 三层确认：「是否确认删除此稿件 / 视频删除后将无法恢复」→ 取消 | 删除
```
**注意有三层**，每层都要过。删除是不可逆的。

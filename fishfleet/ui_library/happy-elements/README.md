## 二、玩法机制（线上攻略整理）

### 特效体系
| 组合 | 效果 |
|---|---|
| 魔力鸟（彩虹猫）+ 魔力鸟 | **全屏消除**（最关键，遇到必换） |
| 魔力鸟 + 炸弹/横纵 | 特效复制 |
| 炸弹 + 炸弹 | 大范围爆炸 |
| 炸弹 + 横纵 | 强化 |
| 横/纵 + 横/纵 | 直接引爆 |

### 障碍物
- **雪块/云层**：在它**旁边匹配**（旁消）即可消除；层数决定旁消次数
- **饼干盒（猫脸木板）**：**累计消除 8 个动物**消掉一个；旁消也有效
- 透明层：所在位置消除后消失
- 小煤球：周围 8 格消除 1 次消失
- 硬币：阻止四消，周围 8 格消除也消失
- 黑毛球：周围 8 格消除 2 次
- 小鸡窝：周围消除 3 次孵化
- 藤框：不能移动

### 通关思路
1. 审题：先看清目标和步数
2. 优先从**底部**消除（下落多、连锁多）
3. 特效优先，特效+特效收益最大
4. 死局果断重开

## 三、棋盘几何（重要）

不同关卡棋盘**列数/位置都不同**，必须每帧自适应：

- 棋盘外接框：用「暗像素投影」找（`v < 0.45` 的列/行，占比 > 12%）
- 行列数：按宽高比取最接近方格的组合，再用「格子中心是否压在深色缝上」选优（正确布局 darkness ≈ 0.001，错误布局 ≈ 0.36）
- 已知尺寸：第 1–13 关常为 9×9；第 16 关 8×8；第 18 关不规则碎块

## 四、自动化脚本

`solver.py`（MCP 的 mobilecli 直调版）：

```
python solver.py <最大步数>
```

能力：
1. 截图 → 自适应识别棋盘（行列数、格子中心）
2. 颜色分类：红狐/黄鸡/绿蛙/蓝猫/紫猫头鹰，雪块、饼干盒、空白、天空
3. 求解所有可行的三消交换，按消除数+靠近障碍排序
4. 滑动执行，**用棋盘区域像素差异**判断是否生效（>5% 视为成功）
5. 无效交换自动拉黑换下一个
6. 自动识别结算页绿「继续」按钮、跳过场动画

`probe_swaps.py`：给定区域逐个试交换，找出真正生效的那一步（调试用）。

## 五、踩过的坑

1. `~/.mobilecli` 残留 `daemon.pid` / `daemon.sock` 会导致 daemon 起不来（`daemon did not start listening within 5s`），改名后恢复
2. 三星「游戏助推器·触控保护」会拦截触摸，需拖动锁图标解锁
3. 屏幕自动变暗会让颜色识别失效，需 `svc power stayon true` + 调亮度
4. 误触「道具商店」内购页（¥1/¥12/¥30/¥68），未购买
5. 「+5 步 59 金币」按钮：金币为 0 时点击会跳商店（银币 ≠ 金币）
6. 结算页再点一次「继续」进入下一关前，可能出现"开局道具"页，需点「首闯/重试」
7. 绿色按钮检测必须限制位置（x 360–720，y 940–1430），否则棋盘里的绿蛙会被误判成按钮

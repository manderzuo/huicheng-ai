## 二、截流主链路 A：搜索 → 用户 → 主页 → 私信（★首选）

```

  → 搜索页 search（输入框 e22，清除 b9r，搜索按钮 plh）
  → 输入关键词 → 点「搜索」
  → 搜索结果 search_result（分栏按 label 点，别按索引）
```

## 三、截流主链路 B：视频 → 评论区 → 评论者（★量大）

```
  → 评论区 comment_panel
```

**要点**：

## 八、状态机的坑（做任务时必看）

1. **发送按钮是「出现型」不是「置灰型」**
   - 私信：空输入时纸飞机不出现；输入后才出现
   - 评论：「发布评论」`bcr` 只在整个输入态容器里，空输入不存在
   - → 守卫写法：**有内容 && 按钮存在** 才允许下一步；反之永远不点

2. **输入首字符容易丢**：点输入框后立刻输入，首字符可能被键盘弹起吞掉（实测 `hi` 只进了 `i`）。正确做法是点输入框 → 等键盘就绪 → 再输入。

3. **输入态会整体换布局**：评论区输入后，表情条从屏幕底部上移到输入框上方，容器 id 全变（`c7v` → `mm9`）。不要用固定坐标找发送键。

4. **搜索分栏顺序会变**：同一账号两次搜索，`综合/用户/视频…` 与 `综合/视频/用户…` 顺序不同。**只能按 label 文本定位**。

5. **空态不是错误**：0 关注/0 粉丝/0 通知都会渲染成引导页（热门创作者、与好友互动、关注你的人会出现在这里…）。这些页面的文案在层级里存在与否不稳定，靠截图兜底。

## 九、截流任务的可组合积木（供后续编排）

| 积木 | 输入 | 输出 | 风险 |
|---|---|---|---|
| 搜索用户 | 关键词 | 用户卡列表（昵称/handle/粉丝数/作品数） | none |
| 进他人主页 | 用户卡 | 主页数据 + 关注/消息按钮 | none |
| 读评论区 | 视频 | 评论者列表（昵称/正文/赞数/时间） | none |
| 打开私信会话 | 他人主页 | 会话输入框 | none |
| 填充私信文本 | 文本 | 输入框有内容 + 发送按钮出现 | none |
| **发送私信** | — | — | **send** |
| 关注 | 用户 | 关注态 | **send** |
| 点赞/收藏 | 视频 | 状态变化 | **send** |
| 发布评论 | 文本 | 评论上屏 | **send** |
| 分享到外部 | 渠道 | 外发 | **send** |
| 推广/余额 | — | — | **forbidden** |

> 组合原则：`none` 级积木可以自动跑；`send` 级必须停下来等人点头。本库只提供积木，不提供「自动截流任务」。

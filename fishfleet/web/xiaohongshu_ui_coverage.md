- 锚点候选：该 Activity、顶部昵称 TextView、消息 RecyclerView、底部 EditText + `发送` TextView。
- 结构：顶部 ImageView 返回、头像 View、昵称 TextView、更多 ImageView；中区消息 RecyclerView；底部输入区 = ImageView（更多）+ **EditText** + ImageView（表情）+ RelativeLayout 内 ImageView。
- ⚠️ **私信页 `发送` 是 TextView 且没有 disabled 标记**（与评论回复框不同）。因此**不能**用 disabled 判断可否发送，必须改为「输入框内容非空」判定，且点击前要二次校验输入框内容与目标昵称。
- 进入会话时页面自动带出引用块：`刚刚浏览对方的评论` + `@<昵称>: <评论原文>` + `发送` + ImageView（清除引用）。这是小红书内置的「评论引用直达私信」行为，可作为合规的触达路径，但也意味着**发送内容会夹带评论原文**，模板设计要避开被引用内容过长。
- 本轮未输入、未发送、未点引用块；无好友/陌生人限制提示出现，未验证不同关系下的差异。

汇城群控AI版 · 新电脑首次使用
================================================
适用：2026-11-07 r7 全量包（免安装，复制即用）


【一、放到哪】
------------------------------------------------
把整个「汇城群控AI版」文件夹复制到**短路径**，例如：

    D:\汇城群控AI版\

不要放在微信/QQ 的接收目录（D:\xwechat_files\...），路径太长会让部分功能异常。


【二、第一次启动】
------------------------------------------------
双击：HuichengFleetAI.exe

首次启动会自动创建 data\ 目录（配置、日志、数据库都在这），不需要安装任何东西。
程序会自己起后端（端口 8765）并打开窗口，大约 10~20 秒。

如果窗口没出来，双击「诊断.bat」，把「诊断结果.txt」发回来。


【三、接手机】
------------------------------------------------
1) 手机开「开发者选项 → USB 调试」
2) 插上 USB，手机上弹「允许 USB 调试吗？」→ 勾「一律允许」→ 点允许
3) 机架上的手机拔不下来时：
      设置 → 开发者选项 → 撤销 USB 调试授权
      → 关掉「USB 调试」再打开 → 弹窗出现 → 勾选 + 允许
4) 在程序目录开 PowerShell 验证：

      .\bin\adb.exe devices

   看到一串 serial + device 就对了。
   unauthorized  = 手机上还没点允许
   列表空        = 驱动问题，双击「adb自检.bat」看提示


【四、装中文输入组件（必做，否则搜中文会把剪贴板内容贴进去）】
------------------------------------------------
双击：手机助手安装.bat

它会逐台装 bin\apk\ADBKeyboard.apk（17 KB），已装的自动跳过。
装完会给你汇总：成功几台 / 跳过几台 / 失败几台。

失败的多半是手机上没点「允许安装」，点一下再重跑即可。

（程序在首次输入中文时也会自动装，这个bat只是批量提前铺好。）


【五、填 AI 配置（用一次就存住）】
------------------------------------------------
打开程序 → 右上角 ⚙ → AI 设置：

  · 「AI 识别」那栏：填对话模型的地址、模型名、API Key（用于看截图/写文案）
  · 「视频生成」那栏：填视频模型的地址和 Key

    地址建议用 AI Work 网关：https://api.gemstory.cn/v1
    填完保存即可，**不要**再手动跑 install.cmd。
    点生成时程序会自动把这份配置加密交给生成服务（DPAPI，明文不落盘）。

Key 只存在本机 data\llm.json，不会进任何交付包。


【六、日常使用】
------------------------------------------------
  启动       双击 HuichengFleetAI.exe
  正常退出   点窗口右上角关闭，或顶栏「⏻ 退出」
             （后台服务、手机通道会在 20 秒内自动收干净）
  强制清场   双击「彻底关闭.bat」

以后升级：把 update.zip 放进本目录，双击「一键更新.bat」。
          也可以直接覆盖新包（data\ 和 runtime\ 不要覆盖）。


【七、出问题怎么报】
------------------------------------------------
按顺序收集这三样，一起发回来最快：

  1) 诊断.bat        → 诊断结果.txt
  2) adb自检.bat     → selfcheck.txt
  3) data\logs\error.log 最后 50 行

手机端的常见现象对照：
  · 搜中文变成旧剪贴板内容 → 没装 ADBKeyboard，跑「手机助手安装.bat」
  · 一台手机都看不到         → adb 驱动/授权问题，跑「adb自检.bat」
  · 点了发布没反应           → 看 data\logs\error.log


【八、目录说明】
------------------------------------------------
  HuichengFleetAI.exe   主程序（双击这个）
  _internal\            程序自己的依赖，不要动
  runtime\              Python / Node / 手机通信层，不要动
  bin\                  adb + apk
  data\                 你的配置、日志、数据库（升级时保留）
  汇城AI安装引导\        环境修复工具（一般用不到）

各工具的用途：
  一键更新.bat      装 update.zip 里的更新
  彻底关闭.bat      清理所有残留进程
  手机助手安装.bat  批量装中文输入组件
  配置视频网关.bat  手动配置视频网关（一般用不到，界面里填即可）
  诊断.bat          收集环境信息
  adb自检.bat       手机连不上时用
  网络检测.exe      pip/网络问题排查
  中文搜索自查.txt  中文输入出问题时的排查步骤
  本版说明.txt      这一版改了什么

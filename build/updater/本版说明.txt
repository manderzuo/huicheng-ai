汇城群控AI版 · 本版更新说明（2026-11-07 r5）
=================================================

【怎么用】
把本压缩包里的所有内容，解压到程序目录（D:\汇城群控AI版\）覆盖同名文件即可。
data\ 和 runtime\ 不在包里，不会被覆盖，你的线索库、配置、运行环境都保留。

覆盖完重启 HuichengFleetAI.exe。


【这一版修了什么】

1. 中文搜索输入（关键）
   现象：搜英文正常，搜中文贴出来的是剪贴板旧内容。
   原因：Mobile MCP 输入中文靠手机里的 devicekit 小助手，新机没装；
         它会退化成"粘贴"，把旧剪贴板内容贴进搜索框。
   修法：中文改走 AdbKeyboard 广播（原生支持中文），不再依赖 devicekit。
         默认输入法仍是 XW；只有输入那一刻临时切到 AdbKeyboard，
         输完立刻切回 XW，你的习惯不变。

2. 关窗口后台残留（上版遗留）
   现象：点了关闭，后台还有 HuichengFleetAI.exe / node.exe / mobilecli 占着。
   修法：关窗口 → 前端发关闭信号 → 停后端 → 关 MCP 通道 →
         停 mobilecli daemon → 兜底清进程树。约 20 秒清干净。

3. 程序"闪一下就没了"（上版遗留的严重 bug）
   现象：打开软件后不显示手机，其实后端已经退出了。
   原因：Edge 复用已有实例时新进程会立即退出，被误判成"用户关窗"。
   修法：启动 15 秒内不判断进程退出；之后也要连续确认 3 秒；
         另加前端心跳兜底（45 秒没心跳才退）。

4. 一键功能空白
   原因：fishfleet/ui_library 目录从来没打进包，actions.json 不存在。
   修法：打进 _internal\fishfleet\ui_library\，51 个动作全部恢复
         （WiFi/蓝牙/飞行模式/旋转/亮度/音量/杀应用/清数据…）。

5. 脚本闪退
   原因：PowerShell 5.1 读取无 BOM 的 UTF-8 脚本会按 GBK 解析，
         中文变乱码导致语法错误，窗口直接关掉。
   修法：所有 .ps1 加 BOM；所有 .bat 加 pause 兜底，出错也看得见。

6. adb 自检脚本报错
   原因：adb_selfcheck.ps1 第 133 行漏写变量名（" = $false"）。
   修法：改为 $devOk = $false。

7. 视频生成"未配置 AIWORK_GATEWAY_BASE_URL"
   原因：视频走本地 MCP 桥，桥不带账号，网关地址和 Key 要本机配一次。
   修法：新增「配置视频网关.bat」——双击，粘贴你的 API Key 即可，
         Key 用 Windows DPAPI 加密存 %APPDATA%\AIWork\seedance-skill.json，
         不会明文落盘，也不会进交付包。


【本版新增的两个工具】

  配置视频网关.bat
      配视频生成的网关地址 + API Key，只需做一次。

  手机助手安装.bat（重写）
      原版要先把 devicekit.apk 放到 bin\apk\ 才能用，现在不需要了。
      双击后会自动给所有在线手机装中文输入助手，已装的自动跳过。
      注：中文输入已改走 AdbKeyboard，本工具属于"双保险"，装不装都能用。


【遇到问题怎么反馈】

  1. 双击「诊断.bat」，把「诊断结果.txt」发回来
  2. 双击「adb自检.bat」，把「selfcheck.txt」发回来
  3. 程序目录下 data\logs\error.log 最后 50 行

  清理残留进程：双击「彻底关闭.bat」。
